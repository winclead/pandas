32. 넓은 데이터를 세로로 길게 풀기 (melt)

Q. 구역별로 나뉜 온도 컬럼을 하나의 '온도' 컬럼으로 합치세요.

장비의 각 구역 온도가 'Zone1', 'Zone2', 'Zone3' 처럼 가로로 넓게(Wide) 기록된 wide_zone_temp.csv 파일이 있습니다. 시계열 모델링을 위해 이를 'WaferID'를 기준으로 세워, 'Zone'이라는 구분 컬럼과 'Temp'라는 값 컬럼으로 길게(Long) 변환하는 코드를 작성하세요.

[AS-IS] 가로로 넓은 데이터 (Wide 포맷)

WaferIDZone1Zone2
W-01100.599.5
W-02101.0100.2

[TO-BE] 세로로 긴 데이터 (Long 포맷)

WaferIDZoneTemp
W-01Zone1100.5
W-02Zone1101.0
W-01Zone299.5
W-02Zone2100.2
💡 방법 1: pd.melt()를 이용한 언피벗(Unpivot)
import pandas as pd
df = pd.read_csv('wide_zone_temp.csv')

# id_vars: 기준이 되어 그대로 유지할 컬럼
# value_vars: 길게 세울 대상 컬럼들 (생략하면 id_vars 제외 전부 세움)
# var_name: 대상 컬럼들의 '이름'이 들어갈 새 컬럼명
# value_name: 대상 컬럼들의 '값'이 들어갈 새 컬럼명
melted_df = df.melt(
    id_vars=['WaferID'], 
    value_vars=['Zone1', 'Zone2'],
    var_name='Zone', 
    value_name='Temp'
)

print(melted_df)
