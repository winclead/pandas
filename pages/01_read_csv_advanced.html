01. 인코딩 및 구분자 문제 해결

Q. 특이한 구분자와 인코딩을 가진 파일에서 특정 열만 로드하세요.

현장 장비에서 추출된 bad_format.csv는 한글 데이터(CP949)가 포함되어 있고, 구분자가 쉼표(,)가 아닌 세미콜론(;)입니다. 이 파일에서 'EqpName'과 'Status' 컬럼만 추출하여 데이터프레임으로 로드하세요.

[AS-IS] 원본 텍스트 데이터 형태

EqpID;EqpName;Status;Temp
EQ-01;식각장비_A;RUN;105.2
EQ-02;증착장비_B;DOWN;42.1
EQ-03;세정장비_C;IDLE;24.5

[TO-BE] 기대 결과 (특정 컬럼만 로드)

EqpNameStatus
0식각장비_ARUN
1증착장비_BDOWN
2세정장비_CIDLE
import pandas as pd # [방법 1] usecols 파라미터 사용 (가장 빠르고 메모리를 덜 먹는 권장 방식) df1 = pd.read_csv('bad_format.csv', sep=';', encoding='cp949', usecols=['EqpName', 'Status']) print("--- [방법 1] 권장 방식 ---") print(df1) # [방법 2] 일단 전체를 로드한 후, 열을 필터링하는 방법 (데이터가 크면 비효율적) df_all = pd.read_csv('bad_format.csv', sep=';', encoding='cp949') df2 = df_all[['EqpName', 'Status']] print("\n--- [방법 2] 전체 로드 후 필터링 ---") print(df2)
