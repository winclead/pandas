10. 쿼리문을 활용한 직관적인 데이터 필터링 (query)

Q. 변수를 활용해 SQL처럼 깔끔하게 조건을 필터링하세요.

조건식이 길어지면 코드가 지저분해집니다. query() 함수를 사용하여 'Recipe == "A"' 이고 'Temp'가 외부 변수 limit_temp보다 큰 데이터를 필터링하는 코드를 작성하세요.

[AS-IS] 전체 공정 레시피 데이터

WaferIDRecipeTemp
W-01A95.0
W-02B105.0
W-03A102.5
W-04A88.0

[TO-BE] query 필터링 (limit_temp = 100 기준)

WaferIDRecipeTemp
2W-03A102.5
💡 방법 1: query() 내에서 외부 변수(@) 활용하기
import pandas as pd
df = pd.read_csv('recipe_data.csv')

# 외부에서 설정된 임계값 변수
limit_temp = 100

# 문자열 조건은 따옴표 처리에 주의 ("A" 처럼 쌍따옴표 사용)
# 외부 변수는 앞에 @ 기호를 붙여 매핑합니다.
result = df.query('Recipe == "A" and Temp > @limit_temp')

print(result)
