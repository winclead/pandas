03. 기초 메타데이터 파악 (info, shape)

Q. 로드한 센서 데이터의 크기와 데이터 타입을 확인하세요.

장비 로그에서 추출한 sensor_info.csv 파일을 로드했습니다. 이 데이터프레임이 몇 행, 몇 열로 이루어져 있는지 확인하고, 각 컬럼의 데이터 타입과 결측치(Null) 여부, 메모리 사용량을 한눈에 요약해서 출력하는 코드를 작성하세요.

[AS-IS] 데이터 로드 직후 상태

데이터가 너무 커서 눈으로 전체를 훑어볼 수 없으며, 분석 전 메모리 용량과 결측치 유무를 빠르게 파악해야 하는 상황입니다.

[TO-BE] info() 출력 요약 형태

RangeIndex: 5 entries, 0 to 4
Data columns (total 3 columns):
 #   Column  Non-Null Count  Dtype  
---  ------  --------------  -----  
 0   EqpID   5 non-null      object 
 1   Temp    4 non-null      float64
 2   Status  5 non-null      object 
memory usage: 248.0+ bytes
💡 방법 1: shape 속성으로 단순 크기(행/열)만 확인하기
import pandas as pd
df = pd.read_csv('sensor_info.csv')

# 튜플 형태로 (행 개수, 열 개수) 반환
print("데이터 형태:", df.shape)
print("행 개수:", df.shape[0])
print("열 개수:", df.shape[1])
💡 방법 2: info() 함수로 전체 메타데이터 요약 보기 (실무 필수)
import pandas as pd
df = pd.read_csv('sensor_info.csv')

# 결측치(Non-Null Count), 데이터 타입(Dtype), 메모리 사용량까지 한 번에 출력
# memory_usage='deep' 옵션을 주면 문자열(object) 메모리까지 정확히 계산합니다.
df.info(memory_usage='deep')
