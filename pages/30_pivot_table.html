Q. '일자별 - 장비별'로 수율 평균이 한눈에 보이는 표를 만드세요.

세로로 길게 누적된 yield_history.csv 데이터를 엑셀의 피벗테이블처럼 구조를 변경하려 합니다. 행(index)에는 'Date', 열(columns)에는 'EqpID', 들어갈 값(values)에는 'Yield'의 평균이 나오도록 구조를 재편성(Reshaping)하는 코드를 작성하세요.

[AS-IS] 세로로 긴 DB형태의 데이터(Long)

DateEqpIDYield
08-13E195
08-13E292
08-14E198

[TO-BE] 보기 편한 매트릭스 형태(Wide)

EqpIDE1E2

💡 방법 1: pd.pivot_table() 사용법 (엑셀과 완벽히 동일)
import pandas as pd
df = pd.read_csv('yield_history.csv')

# index: 세로축(행)으로 깔 기준
# columns: 가로축(열)으로 깔 기준
# values: 표 안을 채울 값
# aggfunc: 값이 여러 개일 경우 어떻게 집계할지 (기본값은 'mean' 평균)
pivot_df = pd.pivot_table(
    df, 
    index='Date', 
    columns='EqpID', 
    values='Yield', 
    aggfunc='mean'
)

print(pivot_df)
