05. 고유값 확인 및 빈도수 분석 (value_counts)

Q. 장비 에러 코드의 발생 횟수와 점유율(%)을 집계하세요.

장비 알람 이력인 error_logs.csv 파일에서 어떤 종류의 에러(ErrorCode)가 많이 발생했는지 분석하려 합니다. 각 에러 코드별 발생 건수를 계산하고, 나아가 단순 건수가 아닌 전체 대비 발생 비율(%)로 변환하여 출력하는 코드를 작성하세요.

[AS-IS] 원본 발생 로그

LogIDErrorCode
1E-001
2E-001
3E-002
4E-001

[TO-BE] 비율(점유율) 요약 도출

ErrorCode
E-001    0.75
E-002    0.25
Name: proportion, dtype: float64
💡 방법 1: 범주별 발생 횟수 카운팅 (내림차순 자동 정렬)
import pandas as pd
df = pd.read_csv('error_logs.csv')

# 특정 컬럼의 고유값과 그 빈도수를 확인 (가장 많이 발생한 순으로 정렬됨)
print(df['ErrorCode'].value_counts())

# 만약 NaN(결측치) 데이터도 카운트하고 싶다면 dropna=False 옵션 추가
# print(df['ErrorCode'].value_counts(dropna=False))
💡 방법 2: 발생 비율(점유율)로 변환 (normalize=True)
import pandas as pd
df = pd.read_csv('error_logs.csv')

# 카운트 대신 0~1 사이의 비율로 반환합니다. (퍼센트로 보려면 * 100)
# 실무에서 "이 불량이 전체 불량의 몇 %를 차지하는가?"를 볼 때 가장 많이 쓰입니다.
print(df['ErrorCode'].value_counts(normalize=True))
