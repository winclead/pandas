Q. 수치형 센서 값과 범주형 장비 상태의 요약 통계를 확인하세요.

sensor_stats.csv를 로드하여 데이터프레임의 요약 통계량을 확인하려 합니다. 온도(Temp), 압력(Pressure) 등 수치형 데이터의 통계량(평균, 최소/최대값)을 구하는 코드와, 상태(Status) 등 문자열 데이터의 최빈값(Top)을 구하는 코드를 각각 작성하세요.

[AS-IS] 원본 데이터

EqpIDTempPressureStatus
E01100.512.1RUN
E01102.111.9RUN
E0245.00.0DOWN

[TO-BE] 수치형 데이터 통계 요약 (describe)

TempPressure
count3.03.0
mean82.538.0
max102.112.1
💡 방법 1: 수치형 컬럼의 통계량 요약 (기본값)
import pandas as pd
df = pd.read_csv('sensor_stats.csv')

# 수치형(int, float) 데이터의 개수, 평균, 표준편차, 최소/최대, 사분위수를 출력
print(df.describe())
💡 방법 2: 범주형(문자열) 데이터 통계량 요약 (include='object')
import pandas as pd
df = pd.read_csv('sensor_stats.csv')

# 문자열(object) 컬럼의 고유값 개수(unique), 최빈값(top), 최빈값 빈도(freq) 출력
print(df.describe(include='object'))
