Q. 특정 문자열 패턴이 포함된 모델명만 골라내세요.

전체 장비 마스터인 equipment_list.csv에서 모델명(Model)에 'ETCH' (식각) 라는 단어가 포함된 장비만 필터링하려고 합니다. 대소문자 구분을 무시하고 포함 여부를 검색하는 코드를 작성하세요.

[AS-IS] 전체 마스터 데이터

EqpIDModel
EQ-01K-Etch-3000
EQ-02Photo-Track-X
EQ-03Clean-Wet-01
EQ-04Super-ETCH-v2

[TO-BE] 텍스트 패턴 필터링 결과

EqpIDModel
0EQ-01K-Etch-3000
3EQ-04Super-ETCH-v2
💡 방법 1: str.contains()와 대소문자 무시 (case=False)
import pandas as pd
df = pd.read_csv('equipment_list.csv')

# case=False: 'etch', 'ETCH', 'Etch' 등을 모두 잡아냅니다.
# na=False: 데이터에 NaN이 있을 경우 발생하는 에러를 방지합니다.
cond = df['Model'].str.contains('ETCH', case=False, na=False)
result = df[cond]

print(result)
💡 방법 2: 특정 단어로 '시작'하거나 '끝나는' 경우 (startswith, endswith)
import pandas as pd
df = pd.read_csv('equipment_list.csv')

# 포함이 아니라, ID가 무조건 'EQ-' 로 시작하는 것만 찾을 때
start_cond = df['EqpID'].str.startswith('EQ-')

# 특정 단어로 끝나는 것 (예: v2로 끝나는 모델)
end_cond = df['Model'].str.endswith('v2')

print(df[start_cond & end_cond])
