02. 대용량 데이터 로드 및 메모리 최적화

Q. 메모리를 초과하는 로그 데이터에서 불량(Fail) 발생 건수만 집계하세요.

huge_log.csv는 수천만 행을 가진 10GB 크기의 센서 데이터로 한 번에 메모리(RAM)에 올릴 수 없습니다. chunksize를 활용해 데이터를 10만 줄 단위로 나누어 읽어오면서, 각 조각(chunk)에서 'Status'가 'Fail'인 건수만 누적해서 계산하는 코드를 작성하세요.

(본 사이트 실습을 위해 다운로드되는 파일은 6줄짜리 미니 버전입니다. chunksize=2로 설정하여 테스트해보세요.)

[AS-IS] 10GB 텍스트 로그 (개념)

LogID,EqpID,Status
1,EQ-01,Pass
2,EQ-02,Fail
3,EQ-01,Pass
4,EQ-03,Fail
5,EQ-02,Pass
6,EQ-01,Fail
... (수천만 줄) ...

[TO-BE] 필요한 최종 결과값 도출

Total Fail Count: 3
import pandas as pd # 전체 Fail 건수를 누적할 변수 초기화 total_fail_count = 0 # chunksize 지정 시 read_csv는 TextFileReader 객체를 반환 (반복문 사용 가능) # 실제 대용량 파일은 100000 등으로 지정 (여기서는 실습용 2 지정) chunk_iter = pd.read_csv('huge_log.csv', chunksize=2) for chunk in chunk_iter: # 각 청크(데이터프레임 조각)에서 Status가 Fail인 행의 개수를 센 후 누적 fail_count = (chunk['Status'] == 'Fail').sum() total_fail_count += fail_count print(f"Total Fail Count: {total_fail_count}")
