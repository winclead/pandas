02. 대용량 데이터 로드 및 메모리 최적화

Q. 메모리를 초과하는 로그 데이터에서 불량(Fail) 발생 건수만 집계하세요.

huge_log.csv는 수천만 행을 가진 10GB 크기의 센서 데이터로 한 번에 메모리에 올릴 수 없습니다. chunksize를 활용해 데이터를 나누어 읽으면서, 각 조각에서 'Status'가 'Fail'인 건수만 누적해서 계산하는 코드를 작성하세요.

(본 사이트 실습을 위해 다운로드되는 파일은 미니 버전입니다. chunksize=2로 설정하여 테스트해보세요.)

[AS-IS] 10GB 텍스트 로그 (개념)

LogID,EqpID,Status
1,EQ-01,Pass
2,EQ-02,Fail
3,EQ-01,Pass
4,EQ-03,Fail
5,EQ-02,Pass
6,EQ-01,Fail

[TO-BE] 필요한 최종 결과값 도출

Total Fail Count: 3
💡 방법 1: 표준 for문 활용 (가독성 우수)
import pandas as pd

total_fail_count = 0
chunk_iter = pd.read_csv('huge_log.csv', chunksize=2)

for chunk in chunk_iter:
    total_fail_count += (chunk['Status'] == 'Fail').sum()
    
print(f"Total Fail Count: {total_fail_count}")
💡 방법 2: 제너레이터 표현식과 sum() 결합 (Pythonic)
import pandas as pd

chunk_iter2 = pd.read_csv('huge_log.csv', chunksize=2)
total_fail_count2 = sum((chunk['Status'] == 'Fail').sum() for chunk in chunk_iter2)

print(f"Total Fail Count: {total_fail_count2}")
