Q. 문자열로 인식된 숫자를 계산할 수 있게 변환하세요.

엑셀에서 추출한 type_error.csv의 'Count' 컬럼이 따옴표가 포함된 문자열(Object)로 인식되어 합계 계산이 안 됩니다. 이를 정수형(int)으로 변경하고, 추가로 메모리 절약을 위해 'Temp' 컬럼을 64비트 실수에서 32비트 실수(float32)로 다운캐스팅하세요.

[AS-IS] 잘못된 타입 (연산 불가 및 메모리 낭비)

Count    object  # '10', '20' 등 문자로 저장됨
Temp     float64 # 불필요하게 큰 자료형 차지

[TO-BE] astype을 통한 타입 캐스팅

Count    int32   # 연산 가능해짐
Temp     float32 # 메모리 용량 절반으로 절감
💡 방법 1: astype()을 사용한 개별 컬럼 형변환
import pandas as pd
df = pd.read_csv('type_error.csv')

# 1. 문자열을 정수(int)로 변환
df['Count'] = df['Count'].astype(int)

# 2. 64비트 float를 32비트 float로 다운캐스팅 (메모리 절약)
df['Temp'] = df['Temp'].astype('float32')

print(df.dtypes)
💡 방법 2: 딕셔너리로 여러 컬럼 한 번에 변환하기
import pandas as pd
df = pd.read_csv('type_error.csv')

# 컬럼명과 타겟 타입을 딕셔너리로 매핑해 한 줄로 처리
df = df.astype({'Count': 'int32', 'Temp': 'float32'})
print(df.dtypes)
