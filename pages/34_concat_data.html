34. 데이터 위아래/좌우로 단순 이어 붙이기 (concat)

Q. 분리된 두 개의 월별 로그 데이터를 하나로 합치세요.

분석을 위해 1월 데이터 log_jan과 2월 데이터 log_feb가 분리되어 있습니다. 두 데이터프레임의 컬럼 구조가 완전히 똑같을 때, 이를 위아래(수직)로 단순 병합하여 하나의 전체 데이터프레임으로 만드는 코드를 작성하세요. (기존 인덱스는 무시하고 0부터 새로 부여해야 합니다.)

[AS-IS] 분리된 두 데이터프레임

df_jan (1월 데이터 1,000행)
df_feb (2월 데이터 1,500행)

[TO-BE] 수직 병합된 단일 데이터프레임

df_total (전체 데이터 2,500행)

💡 방법 1: pd.concat()과 ignore_index=True
import pandas as pd

# (실습을 위한 가상 데이터 생성)
df_jan = pd.DataFrame({'LogID': [1, 2], 'Month': ['Jan', 'Jan']})
df_feb = pd.DataFrame({'LogID': [3, 4], 'Month': ['Feb', 'Feb']})

# 여러 데이터프레임을 리스트 [ ] 로 묶어서 전달합니다.
# ignore_index=True: 각각의 기존 인덱스를 버리고 전체에 0, 1, 2... 새 인덱스를 부여합니다.
df_total = pd.concat([df_jan, df_feb], ignore_index=True)

print(df_total)

# 꿀팁: 가로(좌우)로 이어 붙이고 싶다면 axis=1 을 추가하면 됩니다.
